# Cross-Platform Change Playbook
Updated: 2026-08-21

Changes to Identity Gateway require the current owner, Rahul Verma, and should include Priya Nair for high-risk authentication changes.
Changes that alter OAuth scopes or token lifetime require Ishita Sen from Security Architecture.
Changes to Redis Session Cache behavior should include Rohan Kulkarni from Platform Reliability.

Changes to Checkout API that alter authentication must include Identity & Access.
Changes to checkout event schemas must include Meera Rao from Data Platform.
Project Phoenix releases are coordinated by Neha Iyer, Karan Malhotra and Ananya Gupta.

For a cross-platform incident spanning API Edge, Identity Gateway and Redis Session Cache, Vikram Joshi should coordinate reliability response while Rahul Verma and Rohan Kulkarni investigate the application and cache layers.
