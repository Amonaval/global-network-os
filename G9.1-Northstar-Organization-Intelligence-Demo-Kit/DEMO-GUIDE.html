Step 1 — Create/select Organization

  1. Create/select an Organizational Intelligence network named Northstar Digital Systems.
  2. Make sure your admin account is signed in and this is the active network.
  3. Apply migrations 050, 051, 052 if not already done.

Step 2 — Import graph data

  1. Open Admin → Import Excel or CSV.
  2. Select 01-network-data/northstar-organization-network.csv.
  3. Review preview and Confirm import.
  4. Search Directory for Rahul Verma, Identity Gateway, Checkout API, Event Mesh.

Expected: 32 entities spanning people, teams, products and projects.

Step 3 — Seed baseline human relationships

  1. In Supabase SQL editor run:
    select id,name,vertical_kind from public.networks
where vertical_kind='organization'
order by created_at desc;
  2. Copy Northstar UUID.
  3. Open 01-network-data/seed-baseline-relationships.sql.
  4. Replace YOUR_ORGANIZATION_NETWORK_UUID and run it.
  5. Open Connections in the app and verify reporting/works-with paths.

Step 4 — Configure the full-pipeline runner

  1. Copy 03-runner/run-northstar-full-demo.js into the Knowledge Hub repository root.
  2. Use 03-runner/.env.demo.example as a template for local environment values.
  3. Set NETWORK_ID to the Northstar UUID.
  4. Set the demo Organization admin email/password. Do not commit them.
  5. Ensure Ollama / the existing Knowledge Hub LLM + embedder already works.
  6. Keep INCLUDE_CONFLICT=false initially.

Step 5 — Run real ingest + extraction + handoff

node run-northstar-full-demo.js

The runner signs in, reads live entities, ingests seven documents into an isolated local corpus, persists evidence through G9.1-B RPCs, runs targeted extraction, resolves labels to live entity IDs, and submits candidates to the inbox.

Step 7 — Ask questions that should work well now

  1. Who owns Identity Gateway?
  2. Who knows OAuth 2.0 and OIDC?
  3. What depends on Identity Gateway?
  4. Which systems depend on Identity Gateway, and what does Identity Gateway itself depend on?
  5. Why did we choose Redis for authentication sessions?

Check not just the answer: inspect graph reasons, evidence, confidence and freshness.
