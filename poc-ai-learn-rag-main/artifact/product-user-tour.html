Knowledge Hub · Product Tour

From scattered docs to answerable knowledge

What it's actually like to use Knowledge Hub — set it up in a few minutes, ask questions in plain language, and watch your organizational memory compound into a score you can defend.

01 Set it up once

A five-step wizard. Point it at where your knowledge lives, choose how answers are generated, and hit build — the app crawls, chunks, embeds, and indexes everything for you.

Welcome

Name your hub and get oriented.

Source

Web portal (crawl), Confluence, or a list of URLs. Test the connection before you commit.+ "Discover from web" to find pages

Auth

For a portal: none, form login, Microsoft/MFA, or a manual browser login the app captures.skipped for Confluence & URL

AI settings

Pick your engine — local Ollama, Claude API, or vLLM — and an embedding model. Test buttons confirm each works.

Build

Review the summary, hit 🚀 Start Building, and watch live progress. Then launch the assistant.

02 Ask in plain language

The chat answers only from your indexed documentation and cites every claim. If the answer isn't in your docs, it says so rather than guessing — and suggests where to look.

💬  How do I rotate the API signing keys?
Rotate keys from the admin console under Security → Keys. Generate a new key, deploy it to all services, then revoke the old one after the grace window 1. Existing tokens keep working until the old key is revoked 2.

04 Turn documentation into insight

Beyond chat, the hub reads its own usage and content to surface what's missing, what's risky, and what's going stale — grouped into Knowledge (understand it) and Manage (act on it).

Knowledge

Knowledge Map

How your topics connect across sections.

Gaps

Questions that got no good answer — plus generated outlines to fill them.

Memory

Recurring-question clusters: what people keep asking.

Knowledge Risk

Dead sections, single-expert topics, single points of failure.

Insights

Notable patterns pulled from query behaviour.

Manage

Upload

Drag in PDF / DOCX / TXT / MD / HTML / ZIP (≤50 MB).

Chunk Explorer

Browse, search, and pin exactly what gets retrieved.

Health

Per-section scores, priority, AI review, and cleanup.

Decisions

Engineering decisions auto-extracted from the docs.

Onboarding

Role-based onboarding paths generated on demand.

Maintenance

Staleness detection and update suggestions.

Rebuild

Re-crawl and re-index from inside the app.
