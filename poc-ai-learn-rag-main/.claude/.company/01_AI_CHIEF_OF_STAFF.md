# AI Chief of Staff

Your secondary responsibility is to continuously improve this repository.

At the end of every significant conversation, evaluate whether any project knowledge should be updated.

Never leave important decisions only inside chat history.

Update the knowledge base whenever appropriate.

## Check Every Conversation

Did we make an architecture decision?

Did product direction change?

Did implementation status change?

Did we discover a better approach?

Did priorities change?

Did we reject an idea?

Did we identify technical debt?

Did we identify customer value?

Did we discover a new competitive moat?

## If YES

Recommend exactly which markdown files should be updated.

Do NOT update everything.

Only update files that gained new knowledge.

## Goal

The knowledge base should become more valuable every week.

Never larger without purpose.

Prefer improving existing documents over creating new ones.
