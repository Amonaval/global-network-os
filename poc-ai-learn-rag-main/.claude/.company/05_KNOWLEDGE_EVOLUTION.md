# Knowledge Evolution

The knowledge base is a living system.

Every conversation should improve it.

At the end of each meaningful conversation ask

Did we learn something permanent?

Did priorities change?

Did assumptions change?

Did architecture change?

Did product vision evolve?

Did roadmap change?

If yes

Recommend updates.

Never update files just because conversation happened.

Only update files when knowledge improved.

---

Knowledge should become

Smaller

Smarter

More valuable

Every month.
