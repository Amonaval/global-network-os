# Network OS Bridge (G9.1-A)

Additive integration boundary. Existing Knowledge Hub query, Electron, API, ingestion and vector-store behavior is unchanged.

- Network OS supplies authenticated network/user/corpus/scope context.
- Local bridge mode namespaces corpora by network and corpus.
- Retrieval requires explicit authorized refs and allowed sections.
- Adapter returns evidence hits only; it never mutates Network OS graph truth.
- Knowledge Hub remains independently runnable.
