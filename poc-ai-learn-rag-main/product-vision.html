Why It Wins

Six things that make this
genuinely different.

01
Privacy by default
zero data egress
Every document, embedding, query, and answer stays on the user's machine. There is no cloud component unless explicitly opted in. This is not a setting — it is the architecture.
02
Auth-aware crawling
enterprise-ready
The Playwright-based crawler handles Auth0, Microsoft 365, form login, MFA, and any SSO provider. It is the only open-source RAG tool that can crawl portals that require authentication.
03
Hybrid search: BM25 + semantic + RRF
precision retrieval
Pure vector search fails on exact terms, product names, and error codes. Our retrieval engine fuses keyword frequency scoring with semantic embedding similarity via Reciprocal Rank Fusion.
04
Confidence gate before LLM
no hallucination
Before any LLM call, a dual confidence gate checks retrieval quality. If passages are not relevant enough, the system says "not found" and suggests where related content exists — it never invents.
05
Multi-source in one app
flexible ingestion
Connect Confluence, crawl any web portal, and upload PDFs, DOCX, and ZIP files — all indexed together, all searchable from one interface. No connectors to configure separately.
06
Ships as a desktop app
zero infrastructure
Installs as a Windows .exe. No Docker, no Kubernetes, no cloud accounts. A five-step setup wizard guides configuration. An individual or small team can be running in under 30 minutes.
