Frequently asked questions

Can I run Knowledge Hub completely offline?
Yes. Knowledge Hub is local-first by design. The Individual and Team plans run on your own hardware. The only external calls are to your chosen LLM provider (Ollama, OpenAI-compatible, etc.) — which you can also run locally with Ollama.
What is the VS Code extension?
The VS Code extension lets you ask questions about your documentation without leaving the editor. It connects to your running Knowledge Hub instance and routes queries through the same intelligence layer — so every VS Code query also enriches your IDS.
How does the shared intelligence store work in Team plan?
All team members write queries and signal (gaps, patterns, decisions) to the same eval.jsonl store. The intelligence layer aggregates these across users, so the Documentation Gap analysis and Knowledge Map reflect your entire team's understanding — not just one person's.
What happens to my data if I cancel?
Your data is yours. Knowledge Hub stores everything locally. Cancelling a subscription stops feature access but never touches your data directory. You can export or keep it indefinitely.
Do you offer a hosted trial?
Yes. Email us for a cloud-hosted trial instance pre-loaded with sample documentation. You can experience the IDS flywheel without any local setup.
